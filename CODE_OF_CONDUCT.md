# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep feedback about the code, not the person. Harassment of any kind isn't tolerated.

Report unacceptable behaviour privately to the maintainer via GitHub (@Sahilsalariasoftradix). Reports are handled confidentially.
